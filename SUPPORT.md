# Getting Help

- **Documentation:** [docs.eudiplo.dev](https://docs.eudiplo.dev) covers
  setup, configuration, the API and the supported protocols.
- **Questions:** ask in the [Discord community](https://discord.gg/58ys8XfXDu).
- **Bugs and feature requests:** open an issue in the affected repository, for
  the EUDIPLO service in [EUDIPLO/eudiplo](https://github.com/EUDIPLO/eudiplo/issues).
- **Wallet compatibility:** report results with the wallet compatibility issue
  template in [EUDIPLO/eudiplo](https://github.com/EUDIPLO/eudiplo/issues/new/choose).
- **Community call:** bi-weekly on Thursdays,
  [join via Zoom](https://zoom-lfx.platform.linuxfoundation.org/meeting/94494306854?password=0d272140-5b2b-4bd4-a8fe-0b70efe1aa86).
- **Security vulnerabilities:** follow the [security policy](SECURITY.md); do
  not open a public issue.

EUDIPLO is maintained by volunteers. There is no guaranteed response time
outside of security reports.
