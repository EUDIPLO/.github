# Code of Conduct

EUDIPLO is an [LF Decentralized Trust](https://www.lfdecentralizedtrust.org/)
project and follows the
[LF Decentralized Trust Code of Conduct](https://lf-decentralized-trust.github.io/governance/governing-documents/code-of-conduct/).
By participating in any EUDIPLO repository, issue, pull request, chat or meeting,
you are expected to uphold it.

The Code of Conduct describes how to report unacceptable behavior. You can also
contact the maintainers listed in the `MAINTAINERS.md` file of the repository
concerned.
